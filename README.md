# 📊 Sales Dashboard – Microsoft Excel

## 📌 Project Overview

The **Sales Dashboard** is an interactive data analytics project developed using **Microsoft Excel**. The project is designed to transform raw sales data into meaningful business insights through data analysis, Pivot Tables, KPIs, charts, and an interactive dashboard.

The dashboard provides a simple and effective way to understand sales performance across different products, categories, regions, customers, payment methods, and salespersons. It helps users identify important trends and performance patterns that can support better business decision-making.

This project demonstrates practical skills in **Excel Data Analysis, Data Visualization, Dashboard Development, Pivot Tables, KPI Reporting, and Business Intelligence**.

The main objectives of this project are:

## 🗂️ Dataset Information

The project contains a **SalesData** sheet with sales transaction records.

### Dataset Columns

| Column        | Description                                 |
| ------------- | ------------------------------------------- |
| Order_ID      | Unique identification number for each order |
| Date          | Date of the sales transaction               |
| Customer_Name | Name of the customer                        |
| Region        | Geographical region of the sale             |
| Category      | Product category                            |
| Product       | Product purchased                           |
| Quantity      | Number of units sold                        |
| Unit_Price    | Price of one unit                           |
| Sales         | Total sales value                           |
| Profit        | Profit generated from the transaction       |
| Payment_Mode  | Payment method used                         |
| Salesperson   | Salesperson responsible for the order       |

## 📑 Excel Sheets

### 1. Dashboard

The **Dashboard** sheet provides a visual summary of the sales data. It uses KPIs, charts, and interactive elements to present important business information in an easy-to-understand format.

### 2. SalesData

The **SalesData** sheet contains the main raw sales transaction dataset used for analysis.

### 3. Customer

The **Customer** sheet contains customer-related information used as part of the project.

### 4. Pivot Table

The **Pivot table** sheet contains summarized data created using Excel Pivot Tables. These summaries support the charts and analysis presented in the dashboard.

### 5. About

The **About** sheet provides information about the project and its purpose.
